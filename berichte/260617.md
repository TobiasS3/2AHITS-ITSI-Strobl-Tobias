### Kurz-Zusammenfassung für die Mitschrift

| Befehl      | Bedeutung                              |
| ----------- | -------------------------------------- |
| `xxd datei` | Datei als Hexdump anzeigen             |
| `xxd -p`    | Nur Hex-Zeichen ausgeben               |
| `xxd -r`    | Hexdump zurück in Binärdaten umwandeln |
| `echo -n`   | Ausgabe ohne Zeilenumbruch             |
| `0a`        | Hexwert für Zeilenumbruch (`\n`)       |
| `61`        | Hexwert für `a`                        |
| `c3a4`      | UTF-8 Hexwert für `ä`                  |
| `f09f9883`  | UTF-8 Hexwert für 😃                   |

# Übung (Hex Dump)

## Binärdarstellung mit xxd und hexdump

```bash
xxd -b data.bin
```

zeigt die Daten in Binärform (0 und 1) an.

```bash
hexdump -b data.bin
```

zeigt die Bytes in oktaler Darstellung an.

## Octet

Ein Octet besteht aus genau 8 Bit. Der Begriff wird verwendet, weil ein Byte auf manchen historischen Systemen nicht immer 8 Bit hatte. Ein Octet ist daher eindeutig.

## Option -E von xxd

```bash
xxd -E datei
```

Verwendet die EBCDIC-Zeichendarstellung anstelle von ASCII. Heute ist diese Option kaum noch relevant, da moderne Systeme ASCII bzw. UTF-8 verwenden.

## Bedeutung von printf "%.8x"

```bash
printf "%.8x" 65534
```

wandelt die Dezimalzahl in eine Hexzahl um.

* `%x` → Ausgabe als Hexzahl
* `.8` → immer 8 Stellen ausgeben
* fehlende Stellen werden mit 0 aufgefüllt

Beispiel:

```text
0000fffe
```

## Erklärung der Befehlszeile

```bash
value=65534
printf "%.8x" $value | xxd -r -p > data.bin
```

1. Die Dezimalzahl wird in eine 8-stellige Hexzahl umgewandelt.
2. `xxd -r -p` wandelt die Hexdarstellung in echte Binärdaten um.
3. Die Binärdaten werden in `data.bin` gespeichert.

## Binärwert wieder als Dezimalzahl anzeigen

```bash
od -An -t u4 --endian=big data.bin
```

Dieser Befehl liest die 4 Bytes aus der Datei und gibt sie als Dezimalzahl aus.

## Option -i von xxd

```bash
xxd -i data.bin
```

Erzeugt ein C-Array:

```c
unsigned char data_bin[] = {
  0x00, 0x00, 0xff, 0xfe
};
```
