Hier ist die zu manipulierende Stelle:

```asm
11c8:       0f 84 95 00 00 00       je     1263 <main+0xf3>
```

Dabei ist `11c8` der hexadezimale Offset vom Beginn der Datei.
An dieser Stelle steht der Maschinensprachebefehl `je` (Conditional Jump if Equal).

Wir überschreiben diesen 6 Byte langen Befehl mit `nop`s.

Ein `nop` (no operation) ist ein 1 Byte großer Befehl (`0x90`).

Da der `je`-Befehl hier 6 Byte lang ist, müssen 6 Bytes überschrieben werden.

## Binary patchen

Hexeditor starten:

```bash
$ hexedit pwcheck
```

---

### Schritte im Hexeditor

* `Ctrl + G`
* Offset `11c8` eingeben
* Die 6 Bytes mit `90` überschreiben

Vorher:

```hex
0f 84 95 00 00 00
```

Nachher:

```hex
90 90 90 90 90 90
```

---

### Speichern

```text
Ctrl + X
```

(save and exit)

---

## Programm testen

```bash
$ ./pwcheck
```

---

## Ergebnis

Durch das Patchen der `je`-Anweisung mit `nop` wird die Passwortabfrage umgangen.

Das Passwort lautet:

```text

```

## Übung (jne)

Statt auf nop patche den je (jump if equal) Befehl auf einen jne (jump not equal) Befehl. Hintergrund: der jne Befehl macht genau das Gegenteil des je, damit entsteht das gleiche Ergebnis wie durch das nop-patching.

Teste zuerst im GNU Debugger und fixiere den Patch dann im Programm-Binary.

---

## Lösung

Zuerst wurde die relevante Stelle mit `objdump` gesucht:

```bash
$ objdump -d pwcheck
```

Gefundene Stelle:

```text
11c8:   0f 84 95 00 00 00       je     1263 <main+0xf3>
```

Der Opcode `0f 84` steht für `je`.

Für `jne` lautet der Opcode `0f 85`.

Deshalb wurde nur ein Byte geändert:

Vorher:

```text
0f 84 95 00 00 00
```

Nachher:

```text
0f 85 95 00 00 00
```

### Test im GNU Debugger

```bash
$ gdb ./pwcheck
```

Breakpoint setzen:

```gdb
(gdb) b main
(gdb) run
```

Speicher an der Stelle anzeigen:

```gdb
(gdb) x/6xb 0x11c8
```

Patch setzen:

```gdb
(gdb) set {unsigned char}0x11c9 = 0x85
```

Kontrolle:

```gdb
(gdb) x/6xb 0x11c8
```

Programm fortsetzen:

```gdb
(gdb) c
```

## Permanenter Patch im Binary

Binary mit Hexeditor öffnen:

```bash
$ hexedit pwcheck
```

Dann:

* `Ctrl+G`
* Offset `11c8` eingeben
* Byte `84` auf `85` ändern
* `Ctrl+X` zum Speichern

Danach wurde das Programm erneut gestartet:

```bash
$ ./pwcheck
```

Die Passwortabfrage war nun umgekehrt gepatcht.
