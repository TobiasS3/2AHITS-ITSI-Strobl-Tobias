### Erklärung

- `-m` zählt die Anzahl der Zeichen.
- `-l` zählt die Anzahl der Zeilen.
- `-L` gibt die Länge der längsten Zeile aus.
- `-w` zählt die Anzahl der Wörter.

Der Befehl

```bash
$ echo eins zwei drei | wc - klassenkassa.csv
````

wertet sowohl die Eingabe aus der Pipe (`eins zwei drei`) als auch die Datei `klassenkassa.csv` aus. Für beide Eingaben werden Zeilen-, Wort- und Zeichenzahl sowie eine Gesamtsumme ausgegeben.

## Übung (cut)

### Aufgabe

Recherchiere und experimentiere – cut:

* in welchen Varianten können Felder mit der -f Option angegeben werden?
* was unterscheidet die -c Option von -f?

## Lösung

Unterschied zwischen -c und -f:
```sh
$ cut -c 1-10 klassenkassa.csv
$ cut -d "," -f 2 klassenkassa.csv
```
-c 1-10 gibt die Zeichen 1 bis 10 jeder Zeile aus.
-f 2 gibt das zweite Feld jeder Zeile aus.

### Beispiele

```bash
$ cut -d "," -f 1 klassenkassa.csv
$ cut -d "," -f 1,3 klassenkassa.csv
$ cut -d "," -f 2-4 klassenkassa.csv
$ cut -d "," -f 3- klassenkassa.csv
$ cut -d "," -f -4 klassenkassa.csv
```

## Übung (Werkstatt Summe)

### Aufgabe

Schreibe ein shell Kommando (Einzeiler) das in klassenkassa.csv alle Beträge mit dem Text Werkstatt in folgender Form ausgibt:

```text
3.0+15.0+3.0+13.0+2.5
```

Anleitung:

* Verwende grep um die Zeilen mit Werkstatt zu filtern.
* Verwende nicht die -c Option von grep.
* wende cut auf das Ergebnis an um nur die Geld-Beträge zu filtern.
* Die Beträge stehen nun auf einzelnen Zeilen.
* Verwende das Tool paste um diese zu einer Zeile zusammenzufassen.

## Lösung

```bash
$ grep "Werkstatt" klassenkassa.csv | cut -d "," -f 4 | paste -sd "+" -
```
